# AgentHub 1.3.7 — New agents and RTK

Two new agents, a new companion tool and two discovery fixes.

<!-- more -->

## Agents

New: **CodeWhale** and **MiniMax Code**.

## Companion tool

**RTK** compresses and filters shell output (test runs, `git log`, lint reports) before it reaches the agent's context window, often by 60-90%.
It is off by default; enable it in **Settings > Tools > AgentHub**.

## Fixes

- A deleted Claude Code skill kept in `~/.claude/skills/.trash/` no longer resurfaces as an active one.
- A Codex CLI session with no project directory (an allowed, projectless session since Codex 0.160) is listed instead of dropped.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub) or
search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
