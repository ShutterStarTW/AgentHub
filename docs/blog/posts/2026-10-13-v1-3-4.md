# AgentHub 1.3.4 — Status filter and Junie install

A small release for the Settings tables and Junie CLI.

<!-- more -->

## Settings

- The agent and companion tables have a **status filter**: All, Installed, Not installed, Update available.
- Updatable agents are listed first, then installed, then missing ones.

## Agents

- **Junie CLI** installs with the official installer. The native install updates itself, so it shows `?`
  instead of a false "update available". An npm-managed copy is still checked through npm.

## Updates

- **Update all** waits up to 30 minutes for the results, so a few slow installs no longer time out.
- Files opened from the tool window use the IDE's normal file navigation.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub) or
search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
