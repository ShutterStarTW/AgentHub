# Codebuff - by Codebuff

## Installation

```shell
# Install with npm
npm install -g codebuff

# Update to latest version
npm update --quiet --no-fund -g codebuff

# Uninstall
npm uninstall -g codebuff
```

> via [codebuff.com](https://www.codebuff.com/docs/help/quick-start) &middot; [github.com/CodebuffAI/codebuff](https://github.com/CodebuffAI/codebuff)


## Get Version

```
% codebuff --version
```

## Usage

Codebuff is a terminal coding agent that edits your codebase from natural-language
instructions. The package installs two commands, `codebuff` and `cb`.

```
% cd your-project
% codebuff
# describe a task in natural language and let the agent edit your codebase
```

## Features

- Runs in the terminal against any new or existing codebase
- Works on macOS, Windows, and Linux (requires Node.js)
- The free, ad-supported variant is [Freebuff](freebuff.md)
