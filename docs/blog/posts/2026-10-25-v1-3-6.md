# AgentHub 1.3.6 — New agents and Open in…

Four new agents, four dead ones removed, sortable agent tables and a way to continue a session in another agent.

<!-- more -->

## Agents

- New: **Autohand Code**, **Codebuff**, **Hermes Agent** (Nous Research) and **Letta Code**.
- Removed, because they no longer exist or are no longer maintained:
  **iFlow CLI** (shut down in April 2026), **Qodo** (npm package no longer supported),
  **Cody CLI** (Free and Pro plans ended, Amp replaces it) and **SWE-agent** (maintenance-only;
  its PyPI package was not the agent).
- Pi installs from its new npm package `@earendil-works/pi-coding-agent`, OpenCode from `@opencode/cli`.

## Settings

The **Agent** and **Status** headers of the agent and companion tables sort. Status is the default:
updatable agents first, then installed, missing and unknown.

## Open in…

The session context menu has **Open in…** for Claude Code and Codex sessions.
Oh My Pi, Kilo Code, MiMo Code and OpenCode import the session with their own importer.
AgentHub only starts the command; the target agent writes its own session store.
