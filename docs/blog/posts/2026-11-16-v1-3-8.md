# AgentHub 1.3.8 — Faster tabs and tool window

The tool window opens and switches tabs faster, and the shared cache is smaller.

<!-- more -->

## Performance

- Switching between the Projects and Agents tabs no longer takes seconds with many projects.
- The tool window opens faster.
- The shared environment cache is much smaller: each skill is stored once instead of once per project.
- Loading and saving the shared `~/.agenthub` data is faster.

## Skills

The summary splits its *unknown* targets into **not shared**, **unmanaged** and **unavailable**.

## Discovery

- Sessions of **Kiro CLI V3** and **OpenCode 2.2.6+** are discovered.
- **GitHub Copilot CLI** and **Antigravity CLI** show more instruction, config and skill sources.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub) or
search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
